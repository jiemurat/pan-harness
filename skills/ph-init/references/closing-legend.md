# The closing-line legend

Add this once to the final report, one line a marker, in the owner's language:

- `❓` you answer now.
- `⚠️` a problem or a limit stops the work; you act.
- `👉` you act elsewhere.
- `⏳` an agent works now.
- `💤` nothing runs; it waits for your word.
- `✅` the task is finished.

Then set apart the `⏳` of `plan.md`: there it means an owner check put off for later, not a running agent.
